# Quickstart: Entity Docs Enhancement

## How to document a new entity

1. Run the `main.py` application.
2. Select the entity from the Editor UI palette.
3. Use the **Record Test** (REC) toggle button to save a single instance of the entity.
4. Name the test `single_entity_<entity_name>`.
5. Open `tests/single_entity_<entity_name>/single_entity_<entity_name>.yaml`.
6. Open or create `docs/entity/<entity_name>.md`.
7. Extract the properties and states from the YAML and structure them under the required headers (Description, Summary, Detail, Parameters/Functionality).
