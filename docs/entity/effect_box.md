# Effect Box
**Category**: active  
**Key Bind**: N/A

Visual emitter that triggers particles like confetti or fireworks via signals.

## Required Properties
- `template`: Rectangle
- `is_static`: True
- `width`: 64
- `height`: 64
- `effect_type`: confetti (Options: `confetti`, `firework`, `flare`, `glitter`, `balloon`, `fart`)

## Optional Properties & Defaults
- `color`: `[240, 240, 240]`
